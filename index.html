Mystery Dataset

Learning Objectives

By the end of this activity, you should be able to:

  • Use formulas in spreadsheets to calculate summary statistics
  • Make charts in spreadsheets
  • Discuss the limitations of summary statistics

Instructions

  1. Open the mystery dataset spreadsheet and make a copy (File → Make a copy) so you have your own editable version.

  2. Calculate:

    • Mean
    • Median
    • Mode
    • Correlation (between column1 and column2 for each dataset)
    • Standard Deviation

    Dataset 1 is done for you. Examples of how to write the formulas are in red.

  3. Discuss: describe the 4 mystery datasets using summary statistics—what can you tell me about these mystery data?
